<h2>Тз</h2>

<p>Надо сделать лендинг, визуально похожий на оригинальный сайт продукта, полностью сверстанный вами на html, с чистым кодом и который работает быстро.</p>
<p>Лендинг по цветам, стилям кнопок и другим элементам должен быть похож на оригинальный сайт. Но может быть проще по количеству элементов.</p>
<p>Например, вместо слайдера - 1 слайд, а вместо большого количества картинок со слотами - меньшее. Упор на контент.</p>
<p>Дизайн должен быть аккуратный, акцент на кнопки и бонусы. Все остальное на ваше усмотрение.</p>
<p>После утверждения лендинга надо будет сделать amp версию.(утверждение не требуется)</p>
<p>Основные элементы:</p>
<ol>
    <li> Шапка с лого и кнопками</li>
    <li>Конвертабельный блок с офером и промокодом</li>
    <li>Поле для текста + таблица + скриншоты</li>
    <li>Подвал</li>
</ol>

<h4>Требования к фронту</h4>
<ul>
    <li>Mobile-first.</li>
    <li>Не использовать Bootstrap, Tailwind и другие CSS-фреймворки.</li>
    <li>Структура страницы должна быть логично разделена на секции (header, main, footer, sidebar и т.д.).</li>
    <li>Для типовых макетов использовать Flexbox - для навигации, карточек, выравнивания элементов и построения простых структур.</li>
    <li>Для сложных сеток (галереи, карточки разной высоты, адаптивные таблицы) можно применять CSS Grid.</li>
    <li>Для сложных сеток (галереи, карточки разной высоты, адаптивные таблицы) можно применять CSS Grid.</li>
    <li>Не использовать устаревшие методы (float, table и т.п.) для построения макета</li>
    <li>Не использовать плагины конструкторов шаблонов.</li>
    <li>Не использовать Jquery и другие плагины, необходимо написать решение на чистом js.</li>
    <li>Не использовать ИИ</li>
</ul>
